# 文件核验与设计可行性工作流

## 1. 文档层面的“准确性”定义

本 Skill 的准确性评价限于：

- 来源可追溯；
- 版本和状态明确；
- 定义完整；
- 公式正确；
- 文件之间一致；
- 汇总数字内部自洽；
- 方法与研究目的匹配；
- 结论没有超出证据。

不包括原始数据核查、中心源数据核查、数据库验证、统计程序验证或实验室原始记录审计。

## 3. 设计链检查

### 临床问题和人群

- 拟支持的中国注册决策是否明确；
- 目标年龄、健康状态、既往感染/接种、母传抗体和免疫状态是否与用途一致；
- 年龄递减、特殊人群或加强免疫的证据链是否充分；
- 入排标准是否会削弱代表性或可招募性。

### 干预和对照

- 剂量、剂次、间隔、途径、批次、佐剂和合并接种是否明确；
- 对照选择是否有伦理与方法学依据；
- 确证性试验用疫苗能否代表拟上市产品；
- 是否需要批间一致性、免疫桥接或药学变更后的可比性研究。

### 终点和检测

- 每个主要终点是否能回答主要临床问题；
- 是否将尚未验证的免疫学指标误写为保护替代终点；
- 样本采集时间是否能捕捉峰值、持久性和加强免疫应答；
- 检测方法的验证范围、精密度、特异性和阈值是否支持用途；
- 多抗原/多型别的成功标准是否明确。

### 统计和样本量

- 研究假设、估计量、alpha、把握度、分配比和失访/不可评价率；
- 对照组应答率、GMT变异、病例发生率或人时；
- 非劣效界值或保护效力目标及依据；
- 多重性、中期分析、分层、协变量和敏感性分析；
- 主要分析集与补充分析集；
- 各主要终点样本量取最大值的逻辑。

### 安全性

- 即时观察、征集性局部/全身反应、非征集性AE、SAE、AESI/AEFI的定义和观察窗；
- 体温等测量方法、日记卡和研究者确认；
- 暂停/停止规则、紧急处置、DSMB/IDMC需求；
- 减毒活疫苗的排毒、传播、遗传稳定性和返祖风险；
- 目标人群与样本量是否足以描述常见风险，并明确不能排除罕见风险。

### 运营可行性

- 疾病流行强度、季节、病例积累和中心区域；
- 目标人群规模、筛选失败、既往抗体和既往接种影响；
- 样本采集、冷链、处理、运输、储存和检测通量；
- 访视负担、依从性、失访和加强针时间窗；
- 疫苗供应、对照可获得性和批次；
- 实验室周转时间和数据清理锁库依赖。

## 4. 问题优先级

- **P1 阻断**：可能改变主要终点、受试者保护、样本量、主要结论或注册路径；未解决前不得进入正式决策。
- **P2 重大**：可能造成解释偏差、执行不一致或重要返工；应在定稿/启动前解决。
- **P3 一般**：不改变核心结论，但影响可追溯性、清晰度或效率。

每个问题必须写明：证据位置、问题、影响、建议、责任角色、人工复核节点和关闭条件。

## 5. 停止与降级

资料不足时，不生成虚构的完整评价。将任务降级为以下一种：

- 文件完整性盘点；
- 指标定义缺口表；
- 设计问题清单；
- 官方依据检索计划；
- 待人工确认的参数表。
